# Скрам-покер

Локальный веб-сервис [planning poker](https://en.wikipedia.org/wiki/Planning_poker) для оценки задач. Без внешних зависимостей: Python 3 и браузер.

Откройте одну комнату на команду. Игроки голосуют картами Фибоначчи, ведущий (`viewer`) называет задачу, открывает карты и смотрит историю.

## Как играть

1. Игрок вводит имя, указывает комнату и нажимает **Сесть за стол**.
2. Ведущий входит кнопкой **Viewer** в ту же комнату. Имя с формы ему не нужно.
3. Игроки сразу видят стол. Ведущий вводит номер задачи и нажимает Enter или **Сохранить** — название появляется над столом, у игроков открывается колода.
4. Игроки выбирают карту: `0 1 2 3 5 8 13 21`, плюс ☕ и ⚰️✝️🏳️‍🌈. Пока карты не открыты, оценку можно сменить. Свою карту игрок видит сразу, чужие — рубашкой.
5. Ведущий нажимает **Открыть карты**. Появляется сводка, раунд сохраняется на вкладке **Задачи**.
6. **Новая задача** сбрасывает оценки. **Сброс участников** выгоняет всех из комнаты.

Только `viewer` может сохранять задачу, открывать карты, начинать новый раунд, сбрасывать стол и чистить историю. Голосовать он не может.

Ссылка на комнату копируется кнопкой в шапке (`?room=…`).

## Требования

- Python 3.12+ (стандартная библиотека, пакеты ставить не нужно)
- либо Docker / Podman

## Запуск локально

```bash
python3 server.py
```

Сервер слушает `0.0.0.0:8080`. В консоли будут адреса:

- http://127.0.0.1:8080 — этот компьютер
- `http://<IP>:8080` — другие устройства в сети

История комнат пишется в каталог `data/` (он в `.gitignore`).

## Готовый образ

Собранный образ не хранят в git — его публикует GitHub Actions в [GitHub Container Registry](https://github.com/svoronkin/scrum-poker/pkgs/container/scrum-poker):

```bash
docker pull ghcr.io/svoronkin/scrum-poker:latest
docker run --rm -p 8080:8080 -v poker-data:/app/data ghcr.io/svoronkin/scrum-poker:latest
```

В WSL с rootless Podman порт через pasta Windows не видит. Запускайте с сетью хоста:

```bash
podman pull ghcr.io/svoronkin/scrum-poker:latest
podman run --rm --network=host -v poker-data:/app/data ghcr.io/svoronkin/scrum-poker:latest
```

Дальше в браузере Windows: http://127.0.0.1:8080

## Сборка локально

```bash
docker compose up --build
```

Или вручную:

```bash
docker build -t scrum-poker:latest .
docker run --rm -p 8080:8080 -v poker-data:/app/data scrum-poker:latest
```

С Podman то же самое: `podman build` / `podman run`.

Откройте http://127.0.0.1:8080. Том `poker-data` хранит сохранённые голоса по задачам.
